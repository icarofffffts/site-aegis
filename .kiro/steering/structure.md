# SiteAegis — Project Structure

## Root Layout

```
SiteAegis/
├── src/                    # All application source code
├── dist/                   # Static build output (gitignored)
├── .output/                # SSR server build output (gitignored)
├── vite.config.ts          # Vite + TanStack Start config
├── tsconfig.json           # TypeScript config
├── eslint.config.js        # ESLint config
├── .prettierrc             # Prettier config
├── bunfig.toml             # Bun config
├── Dockerfile              # Container definition
├── docker-compose.yml      # Local container orchestration
└── aegis.nginx             # Nginx config for production
```

│   ├── index.tsx           # Landing page (/)

│   ├── precos.tsx          # Pricing (/precos)

│   ├── dashboard.tsx       # Dashboard (/dashboard)
│   ├── login.tsx           # Login (/login)

│   ├── AegisLogo.tsx       # Brand logo component

## Key Conventions

- **Routes**: Every file in `src/routes/` becomes a route. Use `createFileRoute("/path")` at the top. API routes use `.ts` extension; page routes use `.tsx`.
- **`routeTree.gen.ts`**: Auto-generated — never edit manually. Regenerated on `npm run dev` or `npm run build`.
- **`components/ui/`**: shadcn/ui components — treat as read-only. Add new primitives via the shadcn CLI, not by hand.
- **Page data**: Static data arrays (features, stats, steps) live in the route file itself if page-specific, or in `src/data/` if shared across routes.
- **Imports**: Always use `@/` alias for internal imports (e.g., `import { cn } from "@/lib/utils"`).
- **Layout**: Wrap page content in `<SiteLayout>` for consistent header/footer.
- **Constants**: All external URLs go in `src/lib/constants.ts` under `SITE_URLS`.
