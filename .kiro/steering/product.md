# SiteAegis — Product Overview

SiteAegis is the marketing and landing site for **AegisBot**, the ArxDevs Discord security bot. It serves as the public face of the product, providing:

- Landing page with feature highlights and stats
- Commands reference page (`/comandos`)
- Pricing page (`/precos`)
- Support page (`/suporte`)
- Dashboard (authenticated area)
- Login page

## Brand Identity

- Dark theme, GitHub-inspired color palette (`#0d1117`, `#161b22`, `#30363d`)
- Primary accent: Blue `#3b82f6` / Green `#1f883d` for CTAs
- Language: **Brazilian Portuguese** (pt-BR) throughout all UI copy
- Tone: Professional, security-focused, enterprise-grade

## Part of the ARX Ecosystem

SiteAegis is one of several services under `arxdevs.xyz`. It integrates with:
- AegisBot backend (Discord bot)
- Supabase (data/auth)
- Status Hub (uptime monitoring)
- Evolution API (WhatsApp automation)

Production URL: `https://aegis.arxdevs.xyz`
